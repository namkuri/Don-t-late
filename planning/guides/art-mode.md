# 아트 모드 (민지) — 생성·반입 셀프서비스

> 확정: [decisions](../decisions.md) D-055 (2026-07-22). 민지는 Unity 없이도 돌아가는 게 원칙 —
> 반입하면 검역·배치·프리뷰는 파이프라인(관제)이 처리한다. 산출물 반입도 **브랜치→PR** (main 차단).

## 0. 최초 셋업 (1회)

1. clone 후 `git config core.hooksPath hooks` (라이선스 대조·main 차단 훅 활성)
2. `dontlate.role`은 설정하지 않는다 — main push 자동 차단(브랜치→PR만).
3. Unity는 필수 아님 — 결과 확인은 프리뷰 회신(아래 §3)으로.

## 1. 뭘 만들지 — 작업 카탈로그

- 정본: [BOM.md](../BOM.md) (규격·치수·폴리 상한) + [INBOX](../INBOX.md)의 H-항목(재요청).
- 현재 열린 것 예: H12 편의점 store_2 데시메이트(<3,000tris)+텍스처 · 가로등(<1,500tris)+텍스처 · H9 idle 애니.
- 공통 규격: **FBX Embed Media 필수** · 원점=바닥중심 · 실상표 금지 · min-BOM은 파일명=bom_id ·
  간판 있는 건물은 **간판 분리 익스포트**(별도 메시/머티리얼 — 밤 발광용).

## 2. 반입 절차

```
브랜치 생성 → Assets/_intake/art/<도구명>/<분류>/ 에 파일 추가 → 커밋·push → PR
```
- 폴더 예: `_intake/art/Trellis2/Buildings/` · `_intake/art/Hand/` (수제)
- PR 본문에: 도구·플랜(라이선스 판단 근거)·원파일명·의도한 bom_id 한 줄씩.
- 라이선스·출처 누락은 실격 사유 영역 — 반입 차단(타협 없음).
- **착수 예고 = 발주 커밋 분리 (D-060 — 전 모드 공통, 2026-07-28 남규님 지시로 명시)**: 관제 발주 없이
  **자발 생성·반입을 시작할 때**는 [orders/art.md](../orders/art.md)에 "반입 예고" 한 줄을 append한
  `[발주] 자발: <내용>` 커밋을 먼저 push하고 작업한다 (📦 훅 알림 = 팀 착수 예고). 산출물 반입 커밋과 분리 —
  뭉치면 팀이 무엇이 진행 중인지 커밋 스트림에서 볼 수 없다. 관제가 낸 발주(A-0XX)를 받아 작업하는 경우는
  발주 커밋이 이미 존재하므로 반입 커밋만 하면 된다.

## 3. 회신 (관제가 PR에 남기는 것)

- **검역 리포트**: 폴리 실측·크기·텍스처 유무·경고/차단 (경고는 반입 진행, 개선 재요청만).
- **프리뷰 스크린샷**: 씬에 꽂힌 낮/밤 컷 — Unity 없이 인게임 룩 확인.
- 판정 어휘: ACCEPT / 조건부 ACCEPT(치유 조건) / REJECT(사유) — merge는 관제(남규).

## 4. 팁 (실사고에서 나온 규칙)

- 텍스처가 안 보이면 십중팔구 Embed Media 꺼짐 (가로등·캐릭터 실사례 — 회색 렌더).
- 축이 눕는 문제는 익스포트 시 Y-up 확인.
- 수제 저폴리는 파이프라인 최고 우량 반입물 (box.fbx 106tris — 유일한 예산 통과 사례).

## 5. 디스코드 알림 (선택)

- #git 채널에 발주(📦)·검역 결과·PR 알림이 흐른다 — 반입 후 회신은 PR 코멘트+디스코드로 온다.

## 6. 씬 배치 반입 — 세트 프리팹 (S-118 신설 · 2026-07-30)

> 배치(모델을 씬에 놓는 작업)를 아트가 직접 하고 싶을 때의 공식 경로.
> **씬(.unity) 본문은 절대 커밋하지 않는다** (D-061 — 빌더가 정본·병합 지옥 방지).
> 씬 대신 **배치 묶음 프리팹(세트 프리팹)** 으로 반입한다 — 프리팹은 커밋 가능 대상이다.

### 절차 (Unity에서)

```
임시 빈 씬(저장 안 함) → Prefabs/Auto 프리팹으로 배치 → 빈 루트에 묶기
→ 루트 원점을 바닥 중앙(발 y=0)에 → Assets/Prefabs/Hand/set_<구역명>.prefab 저장
→ 브랜치 커밋(.prefab + .meta) → PR
```

1. **작업 씬은 임시 빈 씬** — File > New Scene. 저장·커밋하지 않는다 (배치 결과는 전부
   프리팹에 담기므로 씬은 버려도 된다).
2. **배치 재료는 `Assets/Prefabs/Auto/`의 카탈로그 프리팹만** — 원본 fbx를 씬에 직접 끌지
   않는다. Auto 프리팹은 스케일 캘리브레이션(인체 1.7u·출입문 2.1~2.4u)·바닥 스냅·콜라이더가
   정규화돼 있고, 원본 재임포트 시 자동 갱신도 상속된다. (fbx를 직접 쓰면 크기·원점이 다 어긋난다.)
3. **빈 GameObject 루트**를 만들어 배치물을 전부 자식으로 — 루트 이름 = 프리팹 이름.
   루트의 원점(position 0,0,0 기준점)이 **바닥 중앙**에 오게 배치물을 정렬한다
   (관제가 씬에 꽂을 때 이 원점을 지면에 스냅한다).
4. 루트를 Project 창의 `Assets/Prefabs/Hand/`로 드래그 → `set_<구역명>.prefab`
   (예: `set_foodalley_corner` · `set_camp_yard` · 소문자·언더스코어). Hand 폴더는 수제
   불가침 — 팩토리가 덮어쓰지 않는다.
5. 새 모델이 필요하면 **§2 반입 절차 선행** (_intake 격리 → 스왑) — 세트 프리팹 안에
   _intake 경로 에셋을 직접 참조하지 않는다 (스왑 시 참조가 끊긴다).
6. 브랜치에 `.prefab` + `.meta` 커밋 → PR. 본문에 "어느 씬 어느 자리 의도인지" 한 줄.

### 관제가 하는 일 (회신)

- 해당 씬 빌더에 `PlaceCatalog("set_xxx", 좌표)` 소켓 한 줄 — 이후 **배치를 수정해 프리팹만
  다시 올리면 씬 재조립 없이 전 PC 반영**된다 (이 방식의 최대 이점).
- 검역 리포트 + 인게임 프리뷰 캡처 회신 (§3과 동일).

### 금지·주의

- ⚠ 씬에 직접 놓고 씬을 저장·커밋 — 빌더 재조립 시 `__gb_` 루트를 갈아엎으므로 직접 놓은
  오브젝트는 **소리 없이 증발하거나 이중 배치**된다. 프리팹 소켓만 재조립에서 살아남는다.
- **스케일 조정 OK (2026-07-30 남규님 판정으로 정정)**: 세트 프리팹 안에서 배치물 크기를
  만지는 것은 오버라이드로 세트에만 저장되고 Auto 원본은 무손상 — 그대로 반입 환영.
  단 "이 모델이 원래부터 항상 크기가 틀리다"(전역 오류)는 세트 안에서 고쳐도 다른 씬에선
  여전히 틀리므로, 그 경우만 한 줄 제보(관제가 ScaleTable 수정 → 전 씬 반영).
- ⚠ 진짜 금지는 하나 — **`Prefabs/Auto/`의 원본 프리팹 파일 자체를 열어 수정·저장**:
  재임포트 시 팩토리가 덮어써 수정분이 증발한다. 인스턴스(씬/세트 안) 오버라이드만.
- 라이선스 기록 규칙(§2)은 세트 프리팹 구성물에도 동일 적용.
