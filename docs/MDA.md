# MDA Canvas — 늦지마 (Don't Late)

> 재미 가설의 기준점 (D-070 도입 · 2026-07-28). 새 기획은 발주 전에 이 캔버스와 대조한다:
> **① 핵심 재미를 강화하는가 ② 약화시키는가 ③ 무관한가** — 판정 1줄을 발주서에 적는다.
> 무관 판정이 쌓이는 축은 후순위. 이 문서는 1페이지를 넘기지 않는다.

## 핵심 가설

> **"이 게임은 마감 압박 속에서 경로·적재·날씨를 즉흥 판단하는 긴장감과,
> 구역을 걸어서 개척하고 장비(구루마→트럭)로 성장하는 성취감이
> 하루 루프로 연쇄되기 때문에 재미있다."**

## Aesthetics — 플레이어가 느끼는 경험

- **MDA-A1 긴장감** — "늦으면 안 된다"는 시간 압박. 게임의 이름이자 심장.
- **MDA-A2 성취감** — 개척(구역 해금)·성장(숙련도·두개들기·구루마·트럭)·정산 보상.
- **MDA-A3 생활감/애착** — 동네 사람들(사장님·노인·행인)·집(가구·고양이)·날씨가 만드는 "여기서 살며 일한다"는 감각.

## Dynamics — 플레이에서 일어나는 행동

- **MDA-D1** ← A1: 마감 시계를 보며 경로(엣지 도보·지름길 계단·차 피하기)와 적재량을 저울질한다.
- **MDA-D2** ← A2: 오늘 번 돈과 숙련도로 다음 확장(새 구역·장비·집)을 계획하고 달성한다.
- **MDA-D3** ← A3: 배송 사이에 딴짓(심부름·고양이·쇼핑·투자)을 하며 동네와 관계를 쌓는다.

## Mechanics — 그 행동을 만드는 규칙

- **MDA-M1** ← D1: 마감·벌금 시스템 + 날씨 페널티(미끄럼·온도 스태미나) + 차량 위험 + 수직 지형(엘베·계단).
- **MDA-M2** ← D2: 구역 개척 언락 + 숙련도 레벨링(성공+/주행+/실패−) + 상점(구루마)·트럭 보상 + 정산·빚 상환.
- **MDA-M3** ← D3: NPC(튜토리얼·격려·심부름)·고양이(급여·도망)·하우징·폰 OS(지도·쇼핑·소셜·날씨).

## 검증 상태

| 항목 | 성공 기준 (관찰 가능) | 상태 |
|---|---|---|
| A1 긴장감 | 플레이어가 마감 때문에 경로/적재를 실제로 바꾸는 장면이 세션당 2회 이상 | ⬜ 미검증 |
| A2 성취감 | 트럭 수령(전 구역 개척) 순간 "됐다"는 반응 · 다음 날 자발 재도전 | ⬜ 미검증 |
| A3 생활감 | 마감과 무관한 행동(고양이 급여·심부름·가구)을 자발적으로 1회 이상 | ⬜ 미검증 |

- 검증 방식: 남규님·팀원 플레이 판정(R 항목) — 판정 요청 시 위 성공 기준을 명시해 묻는다 (D-070).
- 이 캔버스 수정 = 핵심 재미 변경 — 사람 게이트(남규님 승인) 필수.
